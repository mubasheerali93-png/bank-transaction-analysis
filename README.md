# 🏦 Bank Transaction & Fraud Analysis

## 📌 Project Overview
SQL analysis of 1M+ real-world bank transactions to uncover revenue trends, 
fraud patterns, and customer behavior insights using MySQL.

## 🛠️ Tools Used
- MySQL Workbench
- Python (Jupyter Notebook) — for data cleaning

## 📊 Dataset
- 1,048,575 transactions
- 2,000 customers
- 8,914,963 fraud labels
- Source: Kaggle Financial Transactions Dataset

## 🔍 Key Business Questions Answered
1. Which users have the highest transaction volume?
2. Which age group spends the most?
3. Is the business growing or declining over the years?
4. Which transaction type has the highest fraud rate?
5. How are customers segmented by spending?
6. Which age group is most vulnerable to fraud?
7. Who are the high risk customers with poor credit score?

## 💡 Key Insights
- 💳 Online transactions have **88x higher fraud rate** than swipe transactions
- 👴 **46-60 age group** generates the most revenue at $17.3M
- 🚨 **18-30 age group** has the highest fraud rate at 0.24%
- 📉 Business revenue has been **gradually declining** since 2002
- ⚠️ Identified high risk customers with debt **2x their income**

## 🧠 SQL Concepts Used
- JOINS (INNER, LEFT)
- CTEs (Common Table Expressions)
- Window Functions (RANK, SUM OVER)
- CASE WHEN
- Aggregate Functions
- Date Functions
- Subqueries
